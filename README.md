# ABAP

Personal software projects and engineering work.

## Projects

### [ABAP Private](./ABAP-Private/)

A strictly serverless, two-device Android peer-to-peer messaging and voice-calling application. It is designed for exactly two paired phones, using QR-based mutual pairing, direct encrypted connectivity, foreground operation, and configurable message expiry.

See the [ABAP Private overview](./ABAP-Private/README.md), [technical architecture](./ABAP-Private/ARCHITECTURE.md), [security requirements](./ABAP-Private/SECURITY.md), and [development roadmap](./ABAP-Private/ROADMAP.md).
